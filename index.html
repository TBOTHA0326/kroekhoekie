Chapter 3: Functions & Graphs
A function f(x) maps each input x to exactly one output y. Key types: Linear, Quadratic, Exponential, Trigonometric, Hyperbola, Logarithmic...
Key Definition
Domain & Range
Domain: All valid x-values.  Range: All resulting y-values.
EXAM TIP
Always state domain restrictions in your answer. Forgetting that √ requires x ≥ 0 is one of the most common matric mistakes.
